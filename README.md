# Language Practice PWA

A small static app for tracking rotating daily language practice and supplementary activities.

## Run Locally

Open `index.html` directly for basic use. For full PWA behavior, serve the folder over HTTP with any static server and open the local URL.

## Publish On GitHub Pages

1. Push these files to a GitHub repository.
2. In the repository settings, enable GitHub Pages for the branch and folder that contain `index.html`.
3. Open the published Pages URL on your phone and use the browser's install or add-to-home-screen option.

## Backup

Use **Export CSV** to download a backup of the current setup anchor and all activity entries. Use **Import CSV** to restore from a previous export; importing replaces the current local app data.
